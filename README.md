## Contributing

We welcome independently written tutorials, verified commands, sample outputs clearly marked as samples, diagrams, and explanations. Please read [CONTRIBUTING.md](CONTRIBUTING.md) and our [Content Publication Policy](CONTENT_POLICY.md).

## Academic integrity and copyright

Do not upload active graded assessment questions, screenshots of assessments, answer keys, restricted lecture slides or PDFs, copyrighted standards, personal data, credentials, or proprietary teaching material without explicit permission. Create **original** practice questions instead. Respect your institution's policies.

## Security

Only run experiments in systems and networks you own or are explicitly authorized to test. Keep labs isolated, use dummy data, and inspect scripts before running them.
