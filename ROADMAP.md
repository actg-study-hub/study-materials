## Recommended study sequence

1. **Read:** independently written Markdown study notes.
2. **Recall:** explain the key definitions without consulting the guide.
3. **Practice:** attempt original self-assessment questions before revealing the explanations.
4. **Apply:** work through an authorized lab or case study if one is available.
5. **Verify:** cross-check important technical or legal claims against primary public references.
6. **Contribute:** suggest improvements via a pull request or issue after reading the [Content Policy](CONTENT_POLICY.md).

## Legend

- **Published:** A student-created resource is accessible; not a claim that official course material is covered in full.
- **Not yet published:** No resource has been posted here. It does not mean the university did not teach the material.
- **Hands-on:** An optional educational exercise, not necessarily an official homework solution.
