# Contributing

Thanks for helping students learn collaboratively.

1. Add materials to the appropriate course/week directory.
2. Make every guide reproducible: list prerequisites, commands, expected outcomes and limitations.
3. Distinguish actual captured outputs from illustrative examples.
4. Remove names, email addresses, student identifiers, tokens, account details, private IPs or hostnames that could identify someone, and sensitive screenshots.
5. Only include material you created or are licensed to redistribute. No active assessed questions, official answer keys, restricted slides, PDFs, standards, or course handouts.
6. Never include offensive demonstrations targeting real systems. Use isolated, authorized labs.
7. Submit a pull request describing what you changed and how you verified it.
