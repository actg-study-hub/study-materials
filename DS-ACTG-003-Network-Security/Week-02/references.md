# Network Security Week 02 — Public References

These links point to publicly accessible technical documentation. The repository does not mirror third-party text or course slides.

- [NIST CSRC Glossary](https://csrc.nist.gov/glossary) — terminology for confidentiality, integrity and availability.
- [Nmap Project](https://nmap.org/) — network discovery documentation.
- [Wireshark Documentation](https://www.wireshark.org/docs/) — packet inspection.
- [CVE Program](https://www.cve.org/) — vulnerability identifiers.
- [NIST National Vulnerability Database](https://nvd.nist.gov/) — vulnerability catalog.
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) — injection and XSS prevention guidance.
- [RFC 3748: Extensible Authentication Protocol](https://www.rfc-editor.org/info/rfc3748).
- [RFC 4017: EAP Method Requirements for Wireless LANs](https://www.rfc-editor.org/info/rfc4017).
- [RFC 3579: RADIUS Support for EAP](https://www.rfc-editor.org/info/rfc3579).
- [RFC 4511: Lightweight Directory Access Protocol](https://www.rfc-editor.org/info/rfc4511).
- [RFC 5416: CAPWAP Protocol Binding for IEEE 802.11](https://www.rfc-editor.org/info/rfc5416).
- [RFC 6614: RADIUS over TLS](https://www.rfc-editor.org/info/rfc6614).
- [RFC 8907: TACACS+ Protocol](https://www.rfc-editor.org/info/rfc8907).
- [Wi-Fi Alliance](https://www.wi-fi.org/) — certification and Wi-Fi security background.

Technical specifications change; verify implementation guidance against the applicable current standard.
